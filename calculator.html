📱 Modern & Responsive Calculator

The Calculator App is a modern, user-friendly, and responsive calculator designed to work seamlessly on both mobile devices and tablets. It combines a clean interface with advanced features like history tracking.

Built with Flutter, it adapts automatically to different screen sizes:

📲 Mobile layout: Simple, single-screen design with easy navigation to history.
💻 Tablet layout: Split-screen mode showing the calculator on one side and the history panel on the other.

✨ Key Features

✅ Basic & Scientific Calculations (+, −, ×, ÷, √, percentages)
✅ Beautiful User Interface (gradient keypad, 3D shadows, dark theme)
✅ Calculation History with Hive Storage (auto-saved, clear with confirmation, refresh support)
✅ Responsive Design (mobile & tablet dual-pane)
✅ Offline First (no internet required, fast & lightweight)
✅ Custom Branding (personalized icon, splash screen)

🛠️ Tech Stack

Flutter (Dart), Hive (NoSQL), Math Expressions Package, Responsive UI (LayoutBuilder), Custom Splash & Icons.

📊 Example Use Cases

Students solving math problems, professionals doing finance/percentage calculations, anyone needing a fast, reliable calculator with history.

🚀 Why Choose This App?

Unlike standard calculators, this app is responsive, offline, stylish, and history-enabled. It helps you stay organized by remembering your past calculations.
